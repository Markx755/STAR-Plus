# STAR Plus — GitHub Release Edition

ติดตั้งผ่าน GitHub Release ด้วยคำสั่งเดียวใน Termux:

```bash
curl -Ls https://raw.githubusercontent.com/YOUR_GITHUB_USER/YOUR_REPO/main/install.sh | bash
```

Installer จะติดตั้งเครื่องมือที่จำเป็น ดาวน์โหลด `star_plus.zip` จาก Release ล่าสุด และแตกไฟล์ให้พร้อมใช้งาน

## Release Asset

ตั้งชื่อ Asset ให้ตรงกับ:

`star_plus.zip`

โดยภายใน ZIP ต้องมีไฟล์หลักชื่อ:

`star_plus.py`
